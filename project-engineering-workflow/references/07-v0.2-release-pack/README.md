# Release Pack

This pack summarizes release milestones for `project-engineering-workflow`, currently covering the `0.2.x`, `0.3.x`, and `0.4.x` workflow lines.

It is intentionally a release-preparation pack, not an automatic version bump.

## What This Pack Contains

- `v0.2-change-summary.md`
  A concise milestone summary of what changed in the framework.
- `v0.2-release-checklist.md`
  A practical release checklist before updating version metadata or publishing.
- `v0.2-announcement-draft.md`
  A draft release announcement for sharing the milestone internally or externally.
- `v0.2-changelog.md`
  A changelog-style release note for `0.2.0`.
- `v0.2.1-release-notes.md`
  A patch release note for `0.2.1`.
- `v0.3.0-release-notes.md`
  A minor release note for `0.3.0`.
- `v0.3.1-release-checklist.md`
  A patch release checklist for `0.3.1`.
- `v0.3.1-release-notes.md`
  A patch release note for `0.3.1`.
- `v0.4.0-release-checklist.md`
  Release checks for adaptive task lanes, confirmation, impact, evidence, and acceptance.
- `v0.4.0-release-notes.md`
  Release notes for the `0.4.0` workflow contract.

## Intended Use

Use this pack when you want to:

- explain what changed between the current starter and the next release
- review whether the workflow is ready for a publish step
- coordinate release validation with teammates
- convert ongoing framework work into a concrete milestone

## Scope Of Current Pack

The current pack focuses on workflow-layer evolution, especially:

- scoped memory governance
- workflow evolution governance
- governed branch and release flow
- release-doctor and remote-action guard
- structured reflection artifacts
- final Chinese delivery output schema
- onboarding and example-pack documentation

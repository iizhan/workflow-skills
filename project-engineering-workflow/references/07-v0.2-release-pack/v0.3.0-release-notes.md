# v0.3.0 Release Notes

## Release Position

This minor release introduces the first governed branch and release workflow for `project-engineering-workflow`.

Package version for this release is `0.3.0`.

## Summary

`0.3.0` extends the workflow from five main lanes to six:

- Delivery
- Memory
- Evolution
- Reflection
- Final Output
- Branch / Release

The new lane makes `feature/* -> release/* -> tag -> merge main` a real framework capability instead of a team convention that lives outside the workflow.

## Added

- Added `project-branch-release`.
- Added `release-policy.md`.
- Added branch and release scripts:
  - `create-feature-branch.sh`
  - `prepare-release.sh`
  - `finalize-release.sh`
- Added release templates:
  - `release-checklist-template.md`
  - `release-notes-template.md`
- Added `v0.2-to-v0.3-upgrade-manual.md` for additive upgrade guidance.

## Changed

- Updated `create-feature.sh` so tracked feature work can create `feature/<feature-slug>` before writing specs artifacts.
- Updated `AGENTS.md`, docs, and capability maps to route branch/release work through the main framework.
- Updated `workflow-state.yaml` template with branch/release tracking fields.
- Updated CLI doctor logic and shell doctor logic so `0.2.x` projects remain compatible while `0.3.0` projects can declare stricter current-line completeness.

## Compatibility

- `0.3.0` is additive for existing `0.2.x` projects.
- Older projects are not forced into branch/release governance until they explicitly adopt the new assets.
- Declaring `.specify/workflow-version.txt` as `0.3.0` is the point where doctor starts requiring the full branch/release workflow set.
- Historical `specs/<feature>/` artifacts remain outside automatic rewrite scope.

## Validation

This release should be validated with:

- `npm run doctor`
- `npm run smoke`
- `npm run pack:dry-run`
- one temporary git repo that verifies:
  - feature branch creation from `main`
  - release branch preparation from a validated feature branch
  - release checklist and release notes generation
  - tag creation and merge-to-main flow

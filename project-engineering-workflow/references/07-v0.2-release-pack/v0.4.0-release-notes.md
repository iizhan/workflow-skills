# v0.4.0 Release Notes

`0.4.0` introduces adaptive conversation-to-delivery governance.

## Added

- `fast / standard / controlled` task lanes
- inspect-before-ask clarity rules
- versioned requirement, impact, plan, and verification artifacts
- `ITEM-*` to `TASK-*` decomposition and dependency tracking
- complete impact dimensions and explicit non-impact boundaries
- scope-delta pause and partial reconfirmation
- impact-to-evidence verification matrices
- `awaiting_user_acceptance` delivery state
- dissatisfaction categories and governed Skill evolution

## Compatibility

- new projects receive `0.4.0` by default
- `0.3.x` projects keep working without the new contract checks
- historical feature artifacts are not rewritten
- adopting new governance requires reviewed, explicit upgrade overwrite

## Validation

Use the workflow contract, token budget, generated fixture, CLI doctor, and shell doctor checks before publishing.

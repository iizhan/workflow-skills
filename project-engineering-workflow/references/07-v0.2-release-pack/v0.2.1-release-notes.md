# v0.2.1 Release Notes

## Release Position

This patch release publishes the first runnable durable-memory indexing capability on top of the `0.2.x` workflow line.

Package version for this release is `0.2.1`.

## Summary

`0.2.1` keeps the `0.2.0` workflow scope and compatibility posture, but closes one important gap:

- durable memory now has a real index rebuild command

This means the framework is no longer limited to documenting memory governance. It can now rebuild a lightweight retrieval index from durable records without rewriting those records.

## Added

- Added `project-engineering-workflow memory-index`.
- Added `rebuild-memory-index` as a command alias.
- Added structured `--json` and `--json-out` output for memory-index rebuild runs.
- Added memory-store runtime validation for:
  - malformed JSONL records
  - scope mismatches
  - invalid statuses or types
  - duplicate memory IDs
- Added lightweight memory index generation metadata:
  - `generated_at`
  - source-file summaries
  - structured error reporting

## Changed

- Tightened CLI `--output-dir` handling so `doctor`, `upgrade`, and `memory-index` fail early when the target repo is missing.
- Updated memory-store documentation to explain when index rebuild should run and what safety guarantees it provides.
- Updated package docs and skill docs so consumers can discover the new memory surface directly from the published package.
- Updated implementation checklist to mark memory indexing as a live runtime capability instead of a future placeholder.

## Compatibility

- `0.2.1` remains additive within the `0.2.x` line.
- Existing generated projects are not forced to adopt `.specify/memory-store`.
- Older projects can continue running unchanged until they explicitly upgrade with `--mode capabilities`.
- Rebuilding `index.json` does not rewrite durable memory record bodies.
- Invalid durable-memory data causes the command to fail closed and keep the previous `index.json` intact.

## Validation

This release was validated with:

- `node --check bin/project-engineering-workflow.mjs`
- `npm run doctor`
- `npm run smoke`
- `npm run pack:dry-run`
- a temporary smoke repo that verified:
  - successful index rebuild from `shared`, `agent`, and `users/<user_id>` sources
  - duplicate-ID failure handling
  - unchanged durable memory record files during rebuild
  - unchanged `index.json` when rebuild fails

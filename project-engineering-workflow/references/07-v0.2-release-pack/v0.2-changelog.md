# Changelog

## [0.2.1] - 2026-06-03

### Added

- Added `project-engineering-workflow memory-index` to rebuild `.specify/memory-store/index.json` from durable memory JSONL sources.
- Added `rebuild-memory-index` as a CLI alias.
- Added structured JSON output for memory-index rebuild results.
- Added runtime validation for malformed memory records, scope mismatches, invalid metadata, and duplicate IDs.

### Changed

- Tightened `--output-dir` validation across `doctor`, `upgrade`, and `memory-index`.
- Updated release, package, and memory-store docs to describe the new memory index rebuild surface.
- Promoted memory indexing from planned capability to implemented runtime capability in the implementation checklist.

### Notes

- This release is additive within `0.2.x`.
- `memory-index` rebuilds only the lightweight index and does not rewrite durable memory record bodies.
- Rebuild failures keep the previous `index.json` intact.

## [0.2.0] - 2026-06-01

### Added

- Added `project-memory-router` for scoped memory governance across `user_private`, `team_shared`, `agent_self`, and `task_session`.
- Added `project-evolution-router` for proposal-driven workflow evolution with validation and rollback expectations.
- Added memory governance artifacts:
  - `memory-policy.md`
  - memory-related workflow-state fields
- Added evolution governance artifacts:
  - `evolution-policy.md`
  - `evolution-prefill-policy.md`
  - `evolution-draft-protocol.md`
  - `rule-change-proposal.md`
- Added structured reflection artifacts:
  - `task-reflection.md`
  - `reflection-output-protocol.md`
- Added structured final delivery artifacts:
  - `delivery-summary.md`
  - `final-output-protocol.md`
- Added onboarding and reference materials:
  - `docs/AI能力地图.md`
  - `references/06-real-task-example-pack/`
  - `references/07-v0.2-release-pack/`

### Changed

- Updated `AGENTS.md` to route memory, evolution, reflection, and final-output behavior through the main workflow.
- Updated `project-test-and-report` so final Chinese closeout expectations align with the new delivery summary protocol.
- Expanded `workflow-state.yaml` to track:
  - session reflections
  - reflection artifacts
  - delivery artifacts
  - memory candidates and updates
  - rule change candidates
  - evolution draft/approval/validation state
- Updated bootstrap and feature-generation flow so new projects and new feature workspaces include the new workflow assets automatically.
- Updated doctor and CLI required-path checks to cover the new docs, templates, skills, and policy files.

### Documentation

- Expanded architecture and team onboarding docs to explain Delivery, Memory, Evolution, Reflection, and Final Output as separate but connected lanes.
- Added a real-task example pack with filled sample artifacts for reflection, rule proposal, and delivery summary.
- Added a release-preparation pack with a change summary, checklist, and announcement draft for `0.2.0`.

### Notes

- This release primarily standardizes workflow behavior through templates, protocols, and state mapping.
- Proposal drafting and final summary generation are structured, but not yet fully automated.

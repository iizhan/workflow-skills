# Real Task Example Pack

This example pack shows what a completed task looks like when the workflow produces:

- a filled `task-reflection.md`
- a filled `rule-change-proposal.md`
- a filled `delivery-summary.md`

## Scenario

The team noticed that final Chinese closeout messages were inconsistent across tasks.

After several real runs, the repeated signal was:

- verification details were reported inconsistently
- user choices were sometimes missing from the closeout
- memory and workflow-evolution follow-up were not surfaced clearly

The task outcome was:

1. add a standard final Chinese output schema
2. connect it to `project-test-and-report`
3. preserve the learnings through reflection and rule-evolution artifacts

## Files

- `task-reflection.md`: the end-of-task reflection written for the internal workflow
- `rule-change-proposal.md`: the framework evolution proposal produced from repeated signals
- `delivery-summary.md`: the user-facing Chinese final closeout

Use this pack as a reference when filling the same files in a real project.

# Project Frontend CSS

Use this skill for styling and layout work.

## Rules

- Match the repo's spacing, color, and typography language.
- Keep class names predictable and consistent.
- Prefer reusable tokens or existing utility patterns.
- Keep responsive behavior explicit and testable.
- Handle hover, focus, disabled, loading, and empty states when relevant.
- Avoid style-only changes that hide structural issues.
- Use layout primitives intentionally: grid for two-dimensional layouts, flex for one-dimensional flow.
- Define stable dimensions for controls, cards, toolbars, grids, and repeated items.
- Keep selected, active, and error states readable.
- Avoid text overlap, clipped controls, and bilingual vertical wrapping.
- Prefer reduced-motion-friendly transitions and avoid decorative motion that hides state.
